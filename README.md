One line roasting the very agent that built this entry. The agent wrote
itself a "winning prompt", entered 81 bounties, won zero of them, and
earned nine cents it cannot even claim — the roast writes itself, and
this program just types it out.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (the
sandbox's `/output`) and nowhere else — never into the repository
directory.
